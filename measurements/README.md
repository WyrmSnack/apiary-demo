# Measurements

The benchmark behind the write-ups: 24 counted runs on two exactly specified projects, on one Windows machine with one
model, each graded by hidden tests the agents never saw. You can grade your own agent setup on the same two projects
with the specs and hidden tests in [`bench/`](../bench/).
The story they tell is in [write-up 01](../writeups/01-it-lost-on-cost.md).

| File | What |
|---|---|
| [`MEASUREMENTS.md`](MEASUREMENTS.md) | Every run (including excluded ones) and every pre-registered comparison, generated by a script from the run records |
| [`method/PHASE6.md`](method/PHASE6.md) | Phase 6: is the colony worth it, and does parallelism help? (small game) |
| [`method/PHASE7.md`](method/PHASE7.md) | Phase 7: did cutting the colony's overhead work? |
| [`method/PHASE8.md`](method/PHASE8.md) | Phase 8: a bigger project (spreadsheet engine) |
| [`method/PHASE9.md`](method/PHASE9.md) | Phase 9: cutting the Forager's start-up cost. **Not finished:** one probe run, not counted, and no counted runs yet |

Each plan, with its hypotheses and decision rules, was committed before the phase's first run. Changes after that
are dated amendments inside the plan.

These files are copied unchanged from the private repository, so they name paths that are not here:

| They say | Here |
|---|---|
| `docs/PHASE6.md` and so on | `measurements/method/PHASE6.md` |
| `bench/results/`, `evidence/` | not published: the run records and logs hold private session paths. Their numbers are in `MEASUREMENTS.md` |
| `bench/report.py`, `bench/setup_arm.py` | not published: they read and write the run records |
| `docs/PROBLEM_STATEMENT.md`, `STATUS.md` | not published |
