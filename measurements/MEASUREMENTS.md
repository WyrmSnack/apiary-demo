### Limits (Phases 6 and 7)

- One project (`bench/skirmish/SPEC.md`, 8 modules, an exact spec), one machine (Windows 10), one model (the transcripts record it), three runs per arm. A larger or vaguer project could come out differently.
- Output tokens are a lower bound for colony runs: some model calls are logged before their reply finishes (amendment 2). Total tokens move by under 0.3%.
- A colony run shows its plan and waits for approval, so it usually records 1 intervention where a plain run records 0. Interventions are reported, not used for the verdict.
- Every run in every arm passed all 38 hidden tests, so this measures cost, not quality: the project was not hard enough to separate the arms on quality.
