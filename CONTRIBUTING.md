# Contributing

Thank you for wanting to help. **Pull requests from outside the project are not accepted yet.**

The code is AGPL-3.0, and the copyright holder also offers commercial licenses (`LICENSING.md`). Offering
those requires the right to relicense every contribution, which needs a contributor license agreement (CLA).
None exists yet. Until one does:

- **Issues are welcome**: bug reports, conformance failures, places where the spec is unclear.
- **Other implementations of the spec are very welcome.** The spec is CC BY-SA 4.0, and you can implement it
  under any license. Run `conformance/` against yours and tell us what fails.

Every change in this repository is held to the same rules: a failing test before the fix, no weakened tests
(checked by a tool in the private core), and claims in docs tagged Sourced, Measured or Hypothesis.
